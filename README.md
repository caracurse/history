# History Nuclear Treaty Archive

Многостраничный статический сайт-архив по истории международных ядерных договоров.

## Структура проекта

- `index.html` — главная страница с обзором проекта и переходами по разделам.
- `archive.html` — интерактивный архив договоров (timeline + поиск + accordion).
- `documents.html` — раздел документов, публикаций и карт.
- `people.html` — раздел персоналий с якорями для перекрёстных ссылок.
- `assets/styles.css` — единая светлая тема и стили компонентов.
- `assets/app.js` — логика accordion, поиска и timeline-навигации на странице архива.

## Запуск

Откройте любой HTML-файл напрямую в браузере или поднимите локальный сервер:

```bash
python3 -m http.server 8000 --directory .
```
